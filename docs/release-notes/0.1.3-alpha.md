# 小窗 XIAOCHUANGx 0.1.3-alpha 更新说明

项目地址：[zhaozhaozhiyi/XIAOCHUANGx](https://github.com/zhaozhaozhiyi/XIAOCHUANGx)

这一版，小窗继续从“能生成文件”，走向“能管理一个可继续推进的项目”。

在 0.1.2-alpha 里，六个模块入口、3D M1、视频 P0 和桌面发布闸门已经被收束到同一条产品线。0.1.3-alpha 的重点更细，也更接近真实使用：当 Agent 生成了一组文件，用户应该马上知道主产物是什么、哪些可以预览、哪些格式已经生成、接下来能点什么动作。

## 主要更新

交付物卡片升级为项目交付卡。

文档、PPT、3D 等任务的结果不再只是文件列表。小窗开始用结构化 manifest 描述主产物、预览、生成格式和可执行动作。用户可以从卡片里直接打开预览、打开文件，或者基于已有文件继续修改。

3D 绘图更像一个可编辑工作台。

交付卡会优先识别 `drawing.scad` 这类可编辑源文件，也能从“打开模型预览”直接进入 3D 工作区和参数面板。这样用户看到的不只是一个 STL 结果，而是可以继续调参、预览和交付的工程文件。

视频生产路径更清楚。

视频模块新增类型选择：智能选择、视频舞台、屏幕分镜、诗意短动画。除了原来的网页视频舞台和屏幕叙事，现在还新增 p5.js 诗意短动画路径，可以把一个词、概念、情绪或参考画面做成 10-25 秒的视觉短片。

推演画布更容易读懂。

推演节点颜色改成按家族分组：边界、证据、推理、风险、行动、产出。工具栏里也增加了颜色图例，复杂推演图不再只是一堆难以解释的节点颜色。

模块工作台协议开始成型。

小窗新增 Module Adapter 和 Artifact Manifest 两层基础协议，后续写作、PPT、3D、视频、推演都可以逐步走向统一的生命周期、工作台布局和交付动作。

小窗 0.1.3-alpha 的关键词是：**让结果可打开、可理解、可继续改**。
