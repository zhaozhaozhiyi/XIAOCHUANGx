# 小窗 XIAOCHUANGx 0.1.5 更新说明

0.1.5 是 Desktop Alpha 的一次体验补强版本，主要把近期已完成的工作区媒体预览、对话过程状态收束和桌面壳稳定性更新合并为一个清晰版本点。

## 主要更新

- 工作区支持视频文件预览，新增 MP4、WebM、MOV、M4V、OGG/OGV 的识别、MIME 推断和 Range 流式读取。
- 文件查看器补齐 SVG 预览/源码双模式，并让常见源码文件默认进入可直接编辑状态。
- 对话过程状态改为更清晰的中文展示，新增运行中状态色，减少工具状态、推理过程和执行说明的视觉噪音。
- Composer 在窄宽度和换行边界处更稳定，避免输入时在单行/多行模式之间抖动。
- 桌面壳顶部拖拽区域调整为只覆盖空白区域，减少按钮、菜单、设置抽屉被 Electron 拖拽区域抢占的问题。
- 桌面构建链路继续补强图标、嵌入 Web 包、背景 Runtime 和 Playwright ffmpeg 等 release CI 依赖。

## 验收重点

- 打开本地工作区中的视频文件时，可以直接在工作区面板播放或看到编码错误提示。
- 打开 SVG、HTML、CSS、JS/TS、Markdown 等源码文件时，可以直接编辑并保存刷新。
- 对话运行中状态、工具状态和完成状态显示为一致的中文文案。
- 桌面端顶部栏按钮、页签菜单、设置抽屉等控件不再被拖拽区域拦截。
