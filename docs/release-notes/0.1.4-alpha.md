# 小窗 XIAOCHUANGx 0.1.4-alpha 更新说明

项目地址：[zhaozhaozhiyi/XIAOCHUANGx](https://github.com/zhaozhaozhiyi/XIAOCHUANGx)

这一版，小窗重点把“推演画布”从可交互 Demo 收到可解释、可复测、可稳定演示的状态。

0.1.4-alpha 不新增一级业务模块，也不把推演画布扩展成完整图编辑器。它解决的是更基础的使用信任问题：用户点下一个按钮后，应该知道系统把这个动作理解成什么、是否会生成新一轮推演、旧版本是否还能回看。

## 主要更新

推演画布按钮行为被统一定义。

画布内动作现在按本地视图、发起推演、需要确认、读取快照、等待生成等类型统一注册。这样高风险动作不会悄悄执行，低风险动作也会给出清晰反馈。

点击反馈更明确。

新增 Action Receipt。用户点击“查看影响”“继续推演”“生成报告”等动作后，画布会显示目标节点、系统理解、预计影响范围，以及是否可能生成新 Round。

高风险动作统一走确认卡。

变量重算、路径继续、情景继续、风险压力测试、行动执行、历史轮次从此继续等硬选择点都会先进入确认，再发起下一轮 Agent 推演。

问题边界编辑更安全。

Topic 节点新增边界编辑卡。小补充可以作为边界备注处理；核心问题、时间范围、空间范围、主体、变量、初始假设等核心边界变化，会先确认并生成新版世界模型，旧 Round 保留可回看。

历史 Round 和快照链路补齐。

前端新增推演历史 Round 查询与快照读取入口，可以切换历史轮次、回到最新、从历史版本继续推演，并保留分支语义。

画布操作可追溯。

新增最近操作日志，记录最近 12 条有效动作，区分是否会生成新 Round、是否请求报告，帮助演示和排查。

推演画布自动化恢复。

修复 Inspector 遮挡画布节点的问题，扩展 UI smoke 覆盖按钮主链路、确认卡、影响预览、历史轮次、报告预览和操作日志。

小窗 0.1.4-alpha 的关键词是：**让推演过程可解释，版本流可回看，关键选择可确认**。
