# 小窗 XIAOCHUANGx 0.1.6 更新说明

0.1.6 是 Desktop Alpha 的对话结果与处理过程体验收口版本。当前候选包为 `0.1.6-rc.1`，最近正式基线仍是 `0.1.5`。

## 主要更新

- 助手消息固定为“处理过程在上、最终结果在下”，命令、工具和过程旁白不再切断最终回答。
- 处理过程默认收束为 36px 单行摘要，展示当前阶段、文件、命令、失败项和耗时；展开后按真实执行顺序显示精简 Episode。
- 原始 reasoning、状态和工具载荷下沉到二级技术详情，并在展示、格式化和复制前进行递归脱敏与长度限制。
- waiting_user、失败、中断和空结果使用独立 Outcome 提示，部分结果和交付物继续保留。
- 用户展开、收起或阅读长回答时保持视口稳定；临时回答切换为 canonical final 时优先恢复可复用 Markdown 块。
- 长任务运行中，当前处理阶段与多行用户问题组成同一 sticky 栈；任务结束后恢复普通文档流。
- 保留 Codex、Claude、Hermes、Mock、旧历史和推演画布兼容，不修改 ChatPart、SSE、数据库或 CLI parser。
- 提供 `CHAT_ACTIVITY_V2_ENABLED=false` 快速回滚开关，可恢复 0.1.5 交错时间线，无需迁移消息数据。

## 候选版验证

- 40 个 Activity/Turn 纯函数固定场景通过，包括 1000 Part、旧历史无 zone、状态优先级和敏感命令脱敏。
- 22 条 V2 生产服务器 Playwright 回归通过，覆盖聊天、滚动、窄屏、结构化卡片、交付物、写作和 PPT。
- legacy 回滚 Playwright、Codex/Claude/Hermes 真流、Mock 新建会话和推演 UI smoke 通过。
- Web 全量 lint 无 error，TypeScript 与生产构建通过。

## RC 验收重点

- 使用 5～8 个真实长任务完成内部可用性验证，确认用户能快速判断任务是否仍在运行、当前阶段和最终结果位置。
- 安装 macOS 与 Windows 候选包，检查版本号、启动、历史会话、真实 CLI 和回滚开关。
- RC 验收通过前不创建 `v0.1.6` tag，不将候选包标记为正式发布。
