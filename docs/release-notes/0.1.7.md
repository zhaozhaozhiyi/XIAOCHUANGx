# 小窗 XIAOCHUANGx 0.1.7 更新说明

> 状态：**正式发布；T00-T07B 与 macOS/Windows 双平台验收全部通过。**

## 本版本主题

`0.1.7` 将调整 Skill 的使用方式：普通对话不再每次启动都加载固定 Skill，而是在任务确实需要时才选择并读取对应工作流。

当前发布承诺只包含按需 Skill 编排主线。统一任务入口、模板库、多交付物工作台、导航改造和派生任务已经转入独立的 [`0.2.0` 规划](../product/requirements-0.2.0.md)，不再作为 `0.1.7` 的候选或依赖。

本版本包含：

- 寒暄、解释和简短问答可以直接开始，不再显示无实际意义的“正在加载 Skill”；
- 写作、PPT、翻译、行业研究等明确任务仍会获得对应 Skill；
- Skill 由 Companion 统一决定；Codex、Claude、Hermes 不再分别读取 Catalog 后自行判断；
- 自动意图只覆盖少量唯一、高置信规则；模糊请求、slug 引用和日志内容不会触发猜测式选择；
- 同一会话明确继续上一工作流时，可以受约束地延续已经选中的 Skill；
- 每个 Run 都保存可审计的选择决定；过程区只展示真实发生的 Skill bundle 选择、可用、失败和降级；
- Codex、Claude、Hermes 使用一致的 Skill 选择语义。

统一任务模型、统一模板 Catalog/页面、TemplateApplication、多交付阶段和工作台切换仍属于 `0.2.0`。`0.1.7` 仅迁移并消费现有模块的 `templateId` 到 Skill 映射，不新增统一模板产品能力。

完整规划与验收范围见 [`requirements-0.1.7.md`](../product/requirements-0.1.7.md)。

原“过程旁白与业务过程可见性”提案已并入 `0.1.6`，不作为本版本新增内容重复发布。
