# Themes

这个 skill 先内置 3 套主题：

- `signal-room`：高对比、带一点直播控制室气质
- `paper-grid`：纸面编辑、信息密度更高
- `night-theater`：电影感暗场、适合讲述和产品发布

切换主题：

```bash
cp <path-to-screenplay-canvas>/themes/<id>/tokens.css studio/src/styles/tokens.css
```

选主题时先看内容气质，不要先看颜色：

- 强信息、图表、结构化内容：`paper-grid`
- 发布、演示、冲击力：`signal-room`
- 叙事、情绪、镜头感：`night-theater`
